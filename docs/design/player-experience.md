# Player experience

The menu presents a name and entry action. Once captured, the player inhabits a silent unfamiliar landscape without a visible body. Different colours and terrain silhouettes indicate changing regions without labels. Movement and experimentation reveal what can be changed.

No automatic instructions, tutorial, onboarding, control hints, tooltips, block names, biome names, objectives, or map appear in gameplay. This is a deliberate requirement. Do not treat absence of these features as a bug. Technical control documentation lives in README.

Esc returns to the menu and freezes player simulation. Resuming captures the mouse again. Debug information exists only behind explicit developer activation. Operational errors may appear in the menu when the application cannot run; these must not become tutorials.
