# Game vision

Origin is an unknown, harsh, first-person voxel world. The long-term concept is a mutable multiplayer sandbox. This repository is a portfolio-sized technical foundation, not an MMO service or a content-complete survival game.

The first slice demonstrates believable procedural regions, compact mutable terrain, walking and digging, an immutable world floor, and inspectable performance. Correctness, voxel-engine performance, clean boundaries, discovery-driven experience, developer workflow, and visual polish are the priorities, in that order.

No inventory, crafting, combat, NPCs, mobs, quests, building, economy, accounts or production servers are part of this milestone. Adding those as decorative demonstrations weakens the focus and requires changed scope.
